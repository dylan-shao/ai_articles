## GitHub Copilot weekly releases — October 5
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-09
- URL: https://github.blog/changelog/2026-10-09-github-copilot-weekly-releases-october-5/

本周 Copilot 更新里，最重要的是本地沙箱（local sandboxing）在 Copilot CLI、Copilot app 和 VS Code Agent Host 会话中正式 GA，可限制 agent 对文件、网络和凭据的访问。其他值得注意的点包括：Copilot app 支持将 Copilot 许可证账号与代码仓库访问账号分离；Copilot CLI 可通过 /model 发现本地 Ollama 模型；VS Code 支持并排查看多个 agent 会话并清理 worktree 占用。

Why it matters: 这条更新直接触及企业落地 AI coding agent 的核心阻力：执行隔离、身份边界和本地/云模型混合工作流。对于平台团队，这些能力决定了是否能在受控环境中更大规模开放 agent 能力，而不是只停留在个人补全工具阶段。

Key takeaways:
- 本地沙箱 GA 是最强信号，说明 agent 安全边界正从概念走向默认能力。
- 账号分离与本地模型发现降低了企业身份治理和混合部署的摩擦成本。

Tags: AI coding agents, sandboxing, developer tooling, enterprise adoption, local models

## CodeQL 2.27.2 improves C++, Go, Rust, and JavaScript analysis
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-09
- URL: https://github.blog/changelog/2026-10-09-codeql-2-27-2-improves-c-go-rust-and-javascript-analysis/

CodeQL 2.27.2 发布，增强了 C++、Go、Rust 和 JavaScript/TypeScript 的分析能力。更新包括：C++ 对 std::regex 的 ECMAScript 语法解析支持、更多 SQL 注入 sink 与流摘要；Go 增加对 github.com/coder/websocket 的建模；Rust 改进 async/await 数据流并增加 TLS 相关库摘要；JavaScript/TypeScript 增强对 Workflow SDK 指令和 Hapi 路由辅助模式的数据流识别。

Why it matters: 虽然不是 AI coding 直接更新，但这是高价值的工程信号：静态分析的真实能力来自持续补齐框架语义、库模型和数据流边界。对平台/安全负责人而言，这类增量决定了代码扫描误报、漏报和多语言覆盖的实际质量，也影响 AI 生成代码进入 CI 后的治理能力。

Key takeaways:
- 高质量代码安全工具的护城河在于持续建模真实生态，而不是一次性发布。
- 如果团队大量使用 Rust async、Go websocket 或 JS 工作流框架，应评估新版扫描覆盖提升。

Tags: static analysis, CodeQL, application security, CI, multi-language
Scores: signal 7/5, novelty 5/5, actionability 7/5
