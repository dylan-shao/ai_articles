## Introducing Agentic Batch Changes: the frontier agent for code change at scale
- Source: Sourcegraph Blog
- Author: Lauren Preston
- Publish date: 2026-09-14
- URL: https://sourcegraph.com/blog/introducing-agentic-batch-changes

Sourcegraph 推出 Agentic Batch Changes，试图把传统 Batch Changes 从“脚本化批量变更引擎”升级为“可在数百到数千仓库上执行代码迁移的代理式系统”。它瞄准 .NET 升级、废弃 API 替换、CI 配置统一等跨仓迁移场景，核心价值是让单个工程师也能推进大规模代码库级别的变更并跟踪 PR 落地。

Why it matters: 这篇内容的高信号点不在“又一个 coding agent”，而在它把 AI 编码从单仓辅助写代码，推进到组织级变更编排与收敛。对后端/平台负责人来说，真正昂贵的问题通常不是写一个修复，而是如何在异构仓库、漂移配置和不一致实现中安全地把同类修复 rollout 到全代码库。若 Agentic Batch Changes 能稳定处理 repo 差异、生成可审阅 PR 并维持迁移追踪，它会成为平台团队做技术债清理、运行时升级、政策落地和安全修复的重要执行层。

Key takeaways:
- AI 编码的价值重心正在从“生成代码”转向“跨仓迁移执行与闭环跟踪”。
- 大规模代码库治理的关键能力是 repo understanding、差异适配、PR 编排和完成度可观测性，而不只是补全模型本身。
- 这类系统若成熟，会直接改变平台团队处理框架升级、弃用 API、CI/CD 标准化和安全修复的运营方式。

Tags: agentic-coding, batch-changes, repo-understanding, platform-engineering, code-migration, developer-tooling

## Configure cost and quality in Copilot auto model selection
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-14
- URL: https://github.blog/changelog/2026-09-14-configure-cost-and-quality-in-copilot-auto-model-selection/

GitHub 为 Copilot 自动选模增加 efficiency、balance、intelligence 三档，用于在成本、质量和延迟之间做偏好配置。系统仍会按 prompt 逐次选择模型，计费取决于实际命中的模型。

Why it matters: 这条更新技术深度有限，但它反映了 AI 编程工具正在从“给用户一个默认模型”转向“把推理预算治理显式产品化”。对工程负责人而言，这意味着未来 IDE/CLI 级 agent 使用会越来越像云资源管理：不同任务路径需要不同成本上限、延迟目标和质量门槛。

Key takeaways:
- 自动选模开始暴露成本/质量/时延策略，说明 AI 编程正在进入可治理阶段。
- 即使在“intelligence”档位下，系统也会对简单任务回退到更小模型，表明 prompt 级路由将成为默认架构。
