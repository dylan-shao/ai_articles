## CodeQL 2.26.3 improves GitHub Actions queries and JavaScript modeling - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-08-19
- URL: https://github.blog/changelog/2026-08-19-codeql-2-26-3-improves-github-actions-queries-and-javascript-modeling/

GitHub released CodeQL 2.26.3 with better GitHub Actions query accuracy and expanded JavaScript/TypeScript/Vue source and data-flow modeling. Changes include recognizing untrusted input in merge_group events, supporting file-specific custom models via file:<path>, adding remote-flow modeling for Vue Composition API and Vue Router, and improving tracking for Sails Action2 inputs and promise-wrapped response data.

Why it matters: This is not a generic product announcement; it directly affects false-positive/false-negative behavior in code scanning, workflow security coverage, and data-flow analysis quality for modern frontend stacks. For teams maintaining CodeQL, writing custom security queries, or depending on GitHub Advanced Security, these point releases often have outsized impact on real detection outcomes.

Key takeaways:
- GitHub Actions analysis now treats github.event.merge_group as an untrusted source, improving coverage for merge-queue-related attack surfaces.
- The codeql.actions.security.SelfHostedQuery module has been removed, so custom queries depending on it must be updated.
- JavaScript/TypeScript custom models can now target public exports from specific files via file:<path>, enabling more precise repository-local modeling.
- Vue ref/reactive/computed, Vue Router useRoute(), Sails Action2 inputs, and promise-wrapped response propagation all receive stronger taint/remote-flow modeling.
