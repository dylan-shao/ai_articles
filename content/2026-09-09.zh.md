## Enterprise-managed sandbox in Copilot for JetBrains
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-08
- URL: https://github.blog/changelog/2026-09-08-enterprise-managed-sandbox-in-copilot-for-jetbrains/

GitHub 为 JetBrains 中的 Copilot 引入企业托管沙箱策略，可集中控制沙箱启用、文件系统与网络访问、代理设置、开发工具访问、macOS Keychain 访问等；同时加入跨文件 next edit suggestions、聊天中的全局项目上下文、企业策略诊断，以及终端 Copilot CLI 与 JetBrains IDE 会话联动。

Why it matters: 这是 AI coding agent 从“建议生成”走向“受控执行环境”的重要信号。对于平台团队而言，真正的门槛不只是模型质量，而是能否把代理行为约束在企业允许的权限、网络和工具边界内。IDE 侧的集中式沙箱策略，意味着企业终于可以把代理执行安全策略与开发者体验统一起来。

Key takeaways:
- 企业可在 JetBrains 中集中下发 Copilot 沙箱策略，并覆盖用户本地设置。
- 更新不仅是安全控制，还强化了跨文件编辑、项目级上下文和 IDE/CLI 联动，说明 GitHub 正把 Copilot 做成持续会话式代理工作流。

Tags: copilot, jetbrains, sandbox, enterprise-governance, developer-tooling, agent-runtime
Scores: signal 9/5, novelty 8/5, actionability 9/5

## GitHub Enterprise Server 3.22 is now generally available
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-08
- URL: https://github.blog/changelog/2026-09-08-github-enterprise-server-3-22-is-now-generally-available/

GHES 3.22 正式发布，其中最关键的 AI coding 相关能力是：管理员可配置 Copilot CLI 与 GHES 配合使用，面向断网或气隙环境统一设置模型提供方，并让终端用户使用 GHES 凭证访问；此外企业级 teams 正式 GA，secret scanning 审批请求可按日期排序，rulesets 也支持按单个用户做 bypass。

Why it matters: 对很多大型金融、政企、基础设施团队来说，AI coding 的采用瓶颈不是 IDE 插件，而是身份、模型接入、仓库驻留和网络隔离。GHES 3.22 说明 GitHub 正在把 Copilot CLI 带入自托管控制面，这对受监管环境中的组织采用非常关键。

Key takeaways:
- Copilot CLI 开始支持 GHES 场景下的统一模型提供方配置和企业身份接入，尤其面向断网/气隙环境。
- 企业团队管理、规则绕过粒度、secret scanning 审批排序等配套治理能力同步增强，表明 AI coding 采用与仓库治理正在合流。

Tags: ghes, copilot-cli, air-gapped, enterprise-adoption, repo-governance, security
Scores: signal 9/5, novelty 8/5, actionability 8/5
