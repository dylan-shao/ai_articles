## GitHub Copilot suggests custom properties definitions - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-15
- URL: https://github.blog/changelog/2026-09-15-github-copilot-suggests-custom-properties-definitions/

GitHub 在公共预览中为 Copilot Business/Enterprise 增加了仓库自定义属性建议能力：当企业或组织管理员创建新的 custom property definition 时，Copilot 会为 allowed values 提供建议，例如合规标签或 internet-facing 的枚举值。该能力可由新的 Copilot policy 控制启用范围。

Why it matters: 这不是代码补全功能，而是把 AI 引入工程治理元数据层。对于拥有大量仓库的大型组织，ruleset、合规策略、访问控制往往依赖稳定的仓库分类体系；Copilot 开始帮助定义这些分类，说明 AI 编程平台正在进入“策略建模与治理运营”环节。

Key takeaways:
- Copilot 正从开发者工作流扩展到平台治理工作流，服务对象从 individual developer 延伸到 enterprise/org admin。
- 仓库 custom properties 是 ruleset 作用域的重要基础设施，AI 介入其枚举值设计可降低治理体系初始化门槛，但也可能放大错误分类。
