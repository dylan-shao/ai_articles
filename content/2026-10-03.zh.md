## Selected models in GitHub Copilot deprecated
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-02
- URL: https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated/

GitHub 宣布在 Copilot 的所有体验中停用一批模型，包括 Copilot Chat、inline edits、ask/agent 模式与代码补全。被弃用的模型包括 Gemini 3.5 Flash、Gemini 3.6 Flash、Kimi K2.7 Code 和 Claude Opus 4.7，对应建议迁移到 Gemini 3.8 Flash、Kimi K3 与 Claude Opus 5.5。企业管理员可能需要在模型策略中显式启用替代模型。

Why it matters: 这不是功能发布，而是平台兼容性变化：凡是依赖 Copilot 指定模型、做策略白名单、成本控制、回归测试或产线自动化的团队，都需要更新配置和基线。对工程平台负责人而言，模型生命周期管理正成为 AI 编程工具治理的一部分。

Key takeaways:
- Copilot 的多种入口共享同一模型弃用面，说明模型变更会同时影响聊天、编辑、代理与补全工作流。
- 企业版管理员需要检查 model policies，否则替代模型即使可用也可能不会出现在用户选择器或集成流程中。
