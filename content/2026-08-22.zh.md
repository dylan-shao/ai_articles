## The new GitHub Copilot experience in Slack
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-08-21
- URL: https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack/

GitHub 在 Slack 中发布新的 Copilot 体验（公开预览），把 Copilot CLI 与 Copilot app 的代理式能力带入团队对话。用户可在 DM、频道或线程中通过 @GitHub 发起 agent 会话，让其结合对话上下文和授权的 GitHub 上下文来答疑、分诊 bug、更新或创建 issue、调查失败、在安全云沙箱中实施修改并验证结果，最终提交 PR，并把对话链路带入审查流程。

Why it matters: 这不是简单的聊天入口扩展，而是把编码代理嵌入到团队协作主干中：需求澄清、问题分诊、异步执行、PR 交接都可发生在同一协作面。对后端/平台负责人而言，这直接关系到团队如何管理上下文传递、权限边界、审计链路，以及“人类在回路中”的代理治理方式。

Key takeaways:
- Slack 对话可直接成为代理任务入口，减少从讨论到实现之间的上下文丢失。
- GitHub 明确强调安全云沙箱、异步执行与 PR 交付，说明其目标是可监督的代理执行链，而非仅限问答助手。
