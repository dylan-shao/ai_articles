## Enterprise-managed sandbox in Copilot for JetBrains
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-08
- URL: https://github.blog/changelog/2026-09-08-enterprise-managed-sandbox-in-copilot-for-jetbrains/

GitHub added enterprise-managed sandbox policies for Copilot in JetBrains, enabling centralized control over sandbox enablement, filesystem and network access, proxy settings, developer-tool access, macOS Keychain access, and more. The update also adds cross-file next-edit cursor jumps, global project context in chat, enterprise policy diagnostics, and tighter linkage between terminal Copilot CLI sessions and JetBrains IDE sessions.

Why it matters: This is a meaningful step from AI coding as 'suggestion generation' toward AI coding as 'governed execution.' For platform teams, the hard problem is not only model quality but constraining agent behavior within enterprise-approved filesystem, network, identity, and tool boundaries. Centralized IDE-side sandboxing makes that governance operational.

Key takeaways:
- Enterprises can centrally enforce Copilot sandbox policy in JetBrains and override local user settings.
- This is not only a security feature; it also strengthens cross-file editing, project-wide context, and IDE/CLI continuity, pointing to a more persistent agent workflow.

## GitHub Enterprise Server 3.22 is now generally available
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-08
- URL: https://github.blog/changelog/2026-09-08-github-enterprise-server-3-22-is-now-generally-available/

GHES 3.22 is now GA. The most important AI-coding-related capability is that admins can configure Copilot CLI to work with GHES in disconnected or air-gapped environments, set up a model provider once, and let users access it with GHES credentials. The release also GA’s enterprise teams, improves secret-scanning review workflows, and adds per-user bypass support in rulesets.

Why it matters: For many large regulated organizations, the bottleneck for AI coding adoption is not the IDE plugin but identity, model connectivity, repo residency, and network isolation. GHES 3.22 shows GitHub moving Copilot CLI into the self-hosted enterprise control plane, which is critical for adoption in regulated environments.

Key takeaways:
- Copilot CLI is gaining a path into GHES-managed enterprise environments, especially disconnected or air-gapped setups.
- Adjacent governance features—enterprise teams, finer ruleset bypasses, and better secret-scanning review—show AI coding adoption converging with repository governance.

Tags: ghes, copilot-cli, air-gapped, enterprise-adoption, repo-governance, security
Scores: signal 9/5, novelty 8/5, actionability 8/5
