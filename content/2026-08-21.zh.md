## Pinning saved views to the repository issues sidebar is generally available and more - GitHub Changelog
- Source: GitHub Changelog
- Author: Allison
- Publish date: 2026-08-20
- URL: https://github.blog/changelog/2026-08-20-pin-projects-views-and-milestones-to-the-repository-sidebar/

GitHub 为仓库 Issues 侧边栏增加了固定 saved views 的能力，并补充了仪表盘密度调整、reaction 头像显示，以及 issue dependency API 的权限过滤改进。

Why it matters: 这不是 AI 编码核心信号，但它反映出工程工作流承载层在持续优化。对正在把 AI 代理接入 issue 驱动开发流程的团队来说，更稳定的视图入口和更严格的 API 权限边界有一定配套价值。

Key takeaways:
- GitHub 正在增强 issue/work tracking 的日常可用性，这有助于 AI agent 与人类共同围绕 backlog、依赖与状态协作。
- 依赖关系 API 按 token scope 过滤结果，说明平台在自动化集成场景下更重视最小权限边界。

Tags: GitHub Issues, workflow, API permissions, developer productivity
Scores: signal 3/5, novelty 2/5, actionability 3/5
