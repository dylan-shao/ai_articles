## The new GitHub Copilot experience in Slack
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-08-21
- URL: https://github.blog/changelog/2026-08-21-the-new-github-copilot-experience-in-slack/

GitHub released a new Copilot experience in Slack in public preview, bringing the agentic capabilities of Copilot CLI and the Copilot app into team conversations. Users can invoke @GitHub in DMs, channels, or threads to start an agent session that uses conversation context plus permitted GitHub context to answer questions, triage bugs, update or create issues, investigate failures, make and validate changes in a secure cloud sandbox, and finally open a PR linked back to the discussion.

Why it matters: This is more than a chat surface expansion: it embeds a coding agent into the team's primary coordination loop, where scoping, bug triage, asynchronous execution, and PR handoff happen in one place. For backend/platform leaders, it raises practical questions about context transfer, permission boundaries, auditability, and how to run human-in-the-loop governance for coding agents.

Key takeaways:
- Slack conversations can now act as a direct entry point for agent tasks, reducing context loss between discussion and implementation.
- GitHub explicitly highlights secure cloud sandbox execution, asynchronous progress, and PR delivery, signaling a supervised agent execution loop rather than a simple Q&A assistant.
