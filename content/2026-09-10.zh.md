## Enterprise managed permissions for GitHub Copilot agent operations - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-09
- URL: https://github.blog/changelog/2026-09-09-enterprise-managed-permissions-for-github-copilot-agent-operations/

GitHub 为 Copilot Business/Enterprise 提供企业集中式 agent 操作权限控制。管理员可按操作类别定义阻止、需人工审批、或可无提示执行的策略，覆盖 shell 命令、文件读取/修改和网络域访问，并且这些限制不能被用户、本地工作区配置、自动批准或历史批准所削弱。

Why it matters: 这是企业落地 AI coding agent 的关键控制面。相比单纯“开或关”Copilot，这一能力把治理粒度下沉到具体执行面，说明厂商开始把 agent 当作需要策略编排、审计与职责分离的自动化执行主体，而不仅是代码补全工具。

Key takeaways:
- 权限模型覆盖 shell、文件、网络三类高风险 agent 能力，已接近实际开发执行面的核心边界。
- 企业策略优先级高于用户和工作区设置，降低了“本地绕过治理”的风险。

Tags: AI coding agents, governance, enterprise adoption, Copilot
Scores: signal 9/5, novelty 7/5, actionability 9/5

## CodeQL 2.27.0 adds support for Linux ARM64 - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-09
- URL: https://github.blog/changelog/2026-09-09-codeql-2-27-0-adds-support-for-linux-arm64/

CodeQL 2.27.0 新增 Linux ARM64 原生支持，并扩展了 Rust、Java/Kotlin、C# 等语言与框架的检测能力。更新还包括更贴近运行时行为的 ASP.NET Core MVC 控制器/动作发现、OData 参数绑定污点追踪、以及 code scanning 默认配置对私有 registry 凭证的支持。

Why it matters: 虽然它不是 AI coding agent 新闻，但对平台工程和安全工程是高信号更新：ARM64 原生支持减少了异构 CI 基础设施中的摩擦，而更准确的框架建模与私有查询分发能力，直接影响静态分析在大型企业代码库中的覆盖率与可运营性。

Key takeaways:
- Linux ARM64 原生支持意味着安全扫描工具链开始更完整适配 ARM 构建与运行环境。
- 分析精度提升主要来自更贴近真实框架行为的建模，而不只是新增规则数量。

Tags: CodeQL, static analysis, security tooling, ARM64
Scores: signal 8/5, novelty 6/5, actionability 8/5
