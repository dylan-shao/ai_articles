## CodeQL 2.26.3 improves GitHub Actions queries and JavaScript modeling - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-08-19
- URL: https://github.blog/changelog/2026-08-19-codeql-2-26-3-improves-github-actions-queries-and-javascript-modeling/

GitHub 发布 CodeQL 2.26.3，增强了 GitHub Actions 查询准确性，并扩展了 JavaScript/TypeScript/Vue 的源与数据流建模。更新包括识别 merge_group 事件中的不可信输入、支持以 file:<path> 方式为特定文件建模、为 Vue Composition API 与 Vue Router 增加远程流来源识别，以及对 Sails Action2 输入和 promise 包装响应数据的跟踪改进。

Why it matters: 这不是泛泛的产品发布，而是直接影响代码扫描误报/漏报、工作流安全检测覆盖率以及前端框架数据流分析质量的底层规则更新。对维护 CodeQL、自定义安全查询、或依赖 GitHub Advanced Security 的平台团队来说，这类小版本更新往往比大功能发布更能改变实际检测结果。

Key takeaways:
- GitHub Actions 分析现在会把 github.event.merge_group 识别为不可信输入来源，有助于覆盖新的合并队列相关攻击面。
- 移除了 codeql.actions.security.SelfHostedQuery 模块；任何依赖该模块的自定义查询都需要迁移。
- JavaScript/TypeScript 自定义模型现在可通过 file:<path> 精确指向文件公开导出，提升仓库内局部建模能力。
- Vue ref/reactive/computed、Vue Router useRoute()、Sails Action2 inputs 与 promise 响应传播都获得了更好的污点/远程流建模。
