## CodeQL 2.27.2 improves C++, Go, Rust, and JavaScript analysis
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-09
- URL: https://github.blog/changelog/2026-10-09-codeql-2-27-2-improves-c-go-rust-and-javascript-analysis/

CodeQL 2.27.2 adds analysis improvements across C++, Go, Rust, and JavaScript/TypeScript. Changes include ECMAScript regex parsing support for C++ std::regex, additional SQL-injection sinks and flow summaries, new modeling for github.com/coder/websocket in Go, improved async/await data flow and TLS-library summaries in Rust, and better recognition of Workflow SDK directives and Hapi routing helper patterns in JavaScript/TypeScript.

Why it matters: While not a direct AI coding update, this is a strong engineering signal: practical static analysis improves through continual expansion of framework semantics, library models, and data-flow coverage. For platform and security leads, these increments materially affect false positives, false negatives, multilingual coverage, and governance of AI-generated code in CI.

Key takeaways:
- The moat in serious code security tooling is continuous ecosystem modeling, not one-time feature launches.
- Teams heavily using Rust async, Go websocket stacks, or JS workflow frameworks should evaluate the improved scan coverage.

Tags: static analysis, CodeQL, application security, CI, multi-language
Scores: signal 7/5, novelty 5/5, actionability 7/5
