## Enterprise managed permissions for GitHub Copilot agent operations - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-09
- URL: https://github.blog/changelog/2026-09-09-enterprise-managed-permissions-for-github-copilot-agent-operations/

GitHub added centrally managed permissions for Copilot Business/Enterprise agent operations. Admins can mark operation classes as blocked, human-approval-required, or allowed without prompting, covering shell commands, file reads/edits, and network domains; these restrictions cannot be weakened by user settings, workspace settings, auto-approval, or prior approvals.

Why it matters: This is a meaningful control-plane step for enterprise adoption of AI coding agents. Rather than treating Copilot as an all-or-nothing assistant, GitHub is exposing policy at the execution layer, signaling that agents are now being managed more like operational automation with guardrails, approvals, and separation of duties.

Key takeaways:
- The permission model covers three core high-risk agent surfaces: shell, file, and network operations.
- Enterprise policy overrides local/user settings, reducing the chance of governance being bypassed at the workstation level.

Tags: AI coding agents, governance, enterprise adoption, Copilot
Scores: signal 9/5, novelty 7/5, actionability 9/5

## CodeQL 2.27.0 adds support for Linux ARM64 - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-09
- URL: https://github.blog/changelog/2026-09-09-codeql-2-27-0-adds-support-for-linux-arm64/

CodeQL 2.27.0 adds native Linux ARM64 support and expands detection capabilities across Rust, Java/Kotlin, and C#. It also improves ASP.NET Core MVC controller/action discovery, adds taint tracking for OData parameter binding, and allows code scanning default setup to use private registry configuration for fetching custom queries or packs.

Why it matters: While not an AI-agent item, this is still strong signal for platform and security leaders: native ARM64 support lowers friction in heterogeneous CI environments, and improved framework modeling plus private query distribution directly affect static analysis coverage and operability in large enterprises.

Key takeaways:
- Native Linux ARM64 support indicates the security scanning toolchain is catching up with ARM-based build and runtime environments.
- The quality gains come from better runtime-faithful framework modeling, not just adding more rules.

Tags: CodeQL, static analysis, security tooling, ARM64
Scores: signal 8/5, novelty 6/5, actionability 8/5
