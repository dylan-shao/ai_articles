## Kimi K3 is now available in GitHub Copilot
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-08-06T00:00:00+00:00
- URL: https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/

GitHub announced that the open-weight Kimi K3 model is rolling out in GitHub Copilot across VS Code, Visual Studio, Copilot CLI, Copilot cloud agent, GitHub.com, mobile, and JetBrains/Xcode/Eclipse surfaces. GitHub hosts the model on Fireworks AI and exposes it under usage-based billing with published input, output, and cached-input token prices.

Why it matters: For platform and engineering leads, this shows that major AI coding platforms are productizing multi-model choice, third-party hosted models, and usage-based billing. While not a deep technical disclosure, it directly affects how enterprises think about model routing, budget controls, compliance review, and tiered model selection for different coding tasks.

Key takeaways:
- Kimi K3 is entering the GitHub Copilot model picker across IDE, CLI, web, mobile, and cloud-agent surfaces.
- GitHub is using provider-list pricing, giving teams enough transparency to model cost and govern quotas.
