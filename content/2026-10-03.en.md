## Selected models in GitHub Copilot deprecated
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-02
- URL: https://github.blog/changelog/2026-10-02-selected-models-in-github-copilot-deprecated/

GitHub announced deprecation of several models across all Copilot experiences, including Copilot Chat, inline edits, ask/agent modes, and code completions. Deprecated models include Gemini 3.5 Flash, Gemini 3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7, with suggested migrations to Gemini 3.8 Flash, Kimi K3, and Claude Opus 5.5. Enterprise admins may need to explicitly enable replacement models via Copilot model policies.

Why it matters: This is less a feature launch than a platform compatibility change: any team relying on specific Copilot models for policy allowlists, cost controls, regression testing, or production automation needs to refresh configs and baselines. For platform leaders, model lifecycle management is becoming part of AI coding governance.

Key takeaways:
- The deprecation spans multiple Copilot surfaces, implying that model changes can simultaneously affect chat, edit, agent, and completion workflows.
- Enterprise admins need to verify model policies; otherwise replacement models may not appear in user selectors or integration flows even if technically available.
