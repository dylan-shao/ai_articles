## Content exclusions generally available in Copilot app and CLI - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-02
- URL: https://github.blog/changelog/2026-09-02-content-exclusions-generally-available-in-copilot-app-and-cli/

GitHub announced general availability of content exclusion policies in Copilot App and Copilot CLI. Files excluded at the enterprise, org, or repo level will not be used as Copilot context, reducing sensitive-code exposure in agentic workflows.

Why it matters: This is not just a feature toggle; it extends governance controls into the App and CLI, two high-risk surfaces for agentic development. For platform teams, it directly affects whether AI coding can be enabled safely in terminal-driven and multi-repo workflows.

Key takeaways:
- Content exclusion policies now apply to the actual context-ingestion path in Copilot App and CLI.
- The main value is stronger sensitive-code boundary enforcement for agentic workflows, not improved model capability.

## Enterprise-managed settings support any default model - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-02
- URL: https://github.blog/changelog/2026-09-02-enterprise-managed-settings-support-any-default-model/

GitHub now lets enterprises set any Copilot model as the default for new conversations via managed settings, with optional team-specific defaults. Admins can also make the setting overridable so teams can choose their own default model on top of the enterprise baseline.

Why it matters: In a multi-model coding-assistant world, the hard problem is no longer model availability but policy: which model is default, where overrides are allowed, and how to maintain an auditable baseline. This update shows model governance becoming an enterprise configuration problem rather than a personal preference issue.

Key takeaways:
- Enterprises can now bring default-model selection under centralized governance with team-specific mappings.
- The overridable-default mechanism is useful for balancing compliance baselines with team-level optimization.

Tags: Copilot, Model Governance, Enterprise, Developer Tooling, Policy
