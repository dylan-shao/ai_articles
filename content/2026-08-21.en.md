## Pinning saved views to the repository issues sidebar is generally available and more - GitHub Changelog
- Source: GitHub Changelog
- Author: Allison
- Publish date: 2026-08-20
- URL: https://github.blog/changelog/2026-08-20-pin-projects-views-and-milestones-to-the-repository-sidebar/

GitHub added the ability to pin saved views in the repository Issues sidebar, along with dashboard density controls, reaction avatars, and scope-based filtering improvements for issue dependency APIs.

Why it matters: This is not a core AI-coding signal, but it does reflect continued improvement in the workflow substrate. For teams integrating AI agents into issue-driven development, more stable views and tighter API scope boundaries have some supporting value.

Key takeaways:
- GitHub is improving day-to-day issue and work-tracking ergonomics, which helps human and AI-agent collaboration around backlog, dependencies, and status.
- Dependency APIs now filter by token scope, signaling more emphasis on least-privilege boundaries for automation integrations.
