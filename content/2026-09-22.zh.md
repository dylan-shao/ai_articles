## Grok 4.7 is now available in GitHub Copilot - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-21
- URL: https://github.blog/changelog/2026-09-21-grok-4-7-is-now-available-in-github-copilot/

GitHub 宣布在 Copilot 中逐步上线 xAI 的 Grok 4.7，可在 VS Code、Visual Studio、Copilot CLI、JetBrains、Xcode、Eclipse 和 Copilot cloud agent 等入口选择。企业管理员可通过 model policy 控制是否开放该模型，计费采用 provider list pricing 的 usage-based billing。

Why it matters: 这条更新的价值主要在于多模型治理而不是模型本身：它说明企业级 Copilot 正在把“模型选择、访问控制、成本归因”做成标准平台能力。对平台团队而言，这意味着后续内部评测、路由策略和合规审批需要按“可替换模型层”来设计。

Key takeaways:
- Grok 4.7 被纳入 GitHub Copilot 的模型选择器，覆盖 IDE、CLI 与 cloud agent 等多入口。
- 企业与业务版管理员可以通过 model policy 控制启用范围，提示组织级模型治理已成为一等能力。
- 公告没有给出编码基准、代理任务表现、延迟或成本对比，因此当前更适合作为待评测选项而非默认采用依据。
