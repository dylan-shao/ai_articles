## Kimi K3 is now available in GitHub Copilot
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-08-06T00:00:00+00:00
- URL: https://github.blog/changelog/2026-08-06-kimi-k3-is-now-available-in-github-copilot/

GitHub 宣布开源权重模型 Kimi K3 已在 GitHub Copilot 中逐步上线，可在 VS Code、Visual Studio、Copilot CLI、Copilot cloud agent、GitHub.com、移动端以及 JetBrains/Xcode/Eclipse 等入口选择。该模型由 GitHub 托管在 Fireworks AI 上，并采用 usage-based billing，公开了输入、输出与缓存输入 token 的价格。

Why it matters: 对平台与工程负责人而言，这表明主流 AI 编程平台正在把多模型选择、第三方模型托管和按量计费进一步产品化。虽然这不是深入技术披露，但它直接影响企业如何做模型路由、预算控制、合规审批以及针对不同编程任务的模型分层配置。

Key takeaways:
- Kimi K3 已进入 GitHub Copilot 的模型选择器，并覆盖从 IDE 到 cloud agent 的多种使用入口。
- GitHub 明确采用 provider list pricing 计费，价格透明化有助于团队做成本模型与配额治理。
