## GitHub Copilot suggests custom properties definitions - GitHub Changelog
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-09-15
- URL: https://github.blog/changelog/2026-09-15-github-copilot-suggests-custom-properties-definitions/

GitHub has added a public-preview Copilot capability for Business and Enterprise plans that suggests allowed values when enterprise or organization admins create new repository custom property definitions. Examples include compliance-oriented values for properties like FedRAMP and enumerations such as yes/no for internet-facing. The feature can be governed via a dedicated Copilot policy.

Why it matters: This is not a coding-assist feature but an application of AI to the governance metadata layer. In large organizations, rulesets, compliance policies, and access controls depend on a stable repository taxonomy; Copilot helping define that taxonomy indicates AI coding platforms are moving into policy modeling and governance operations.

Key takeaways:
- Copilot is expanding from developer workflows into platform-governance workflows, targeting enterprise and organization admins rather than only individual developers.
- Repository custom properties are foundational for ruleset scoping; AI assistance can lower the setup barrier for governance taxonomies, but it can also amplify misclassification if left unreviewed.
