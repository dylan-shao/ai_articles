## GitHub Copilot code review: API support and new default effort level
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-02
- URL: https://github.blog/changelog/

GitHub 在 Changelog 中发布了 Copilot 代码评审的新能力：提供 API 支持，并调整了默认 effort level。虽然公开信息较短，但这表明 Copilot code review 正在从交互式产品功能转向可编程平台能力。

Why it matters: 对于后端、平台和工程效率负责人，这意味着 AI 代码评审可以更容易嵌入 CI、合规检查、PR 路由和内部开发者门户。默认 effort level 的变化也说明模型推理预算、延迟与审查深度开始成为可运营的参数，而不只是 UI 选项。

Key takeaways:
- 代码评审 API 化是从“Copilot 助手”走向“Copilot 可编排服务”的重要一步。
- effort level 的默认值调整反映出供应商正在主动权衡评审质量、时延和成本。

Tags: GitHub Copilot, Code Review, API, Developer Tooling, Agentic Workflow

## GitHub Copilot can now interact with desktop apps with computer use
- Source: GitHub Changelog
- Author: N/A
- Publish date: 2026-10-01
- URL: https://github.blog/changelog/

GitHub 宣布 Copilot 现在可以通过 computer use 与桌面应用交互。这类能力通常意味着代理不仅能生成代码，还能跨 IDE、终端、浏览器或本地工具执行多步操作。

Why it matters: 这对工程平台团队是强信号：未来的开发者工具链将不再只暴露 API，也要考虑 GUI 自动化、安全沙箱、权限边界、审计日志和失败恢复。它也会改变内部工具设计方式，因为很多尚未 API 化的流程现在可以先由桌面代理桥接。

Key takeaways:
- computer use 扩展了 AI 编码代理的执行面，从代码建议走向真实环境操作。
- 组织采用时需要优先评估权限控制、可观测性和桌面级安全策略。

Tags: GitHub Copilot, Computer Use, Agent, Desktop Automation, Security
Scores: signal 7/5, novelty 7/5, actionability 6/5
