GitHub Apps can now access enterprise billing data

  • Source: GitHub Changelog
  • Author: N/A
  • Publish date: 2026-08-26
  • URL: https://github.blog/changelog/2026-08-26-github-apps-can-now-access-enterprise-billing-data/

GitHub now lets enterprise owners grant GitHub Apps an enterprise billing permission with read or read-and-write scopes. Enterprise billing REST APIs, which previously depended on a human user's personal access token, can now be accessed via app installation tokens for usage export, budget management, and cost-center workflows, with higher rate limits than PATs.

Why it matters: For platform teams, this is more than a billing feature: it improves the identity model for enterprise automation. Moving critical finance and governance integrations from person-bound tokens to app-bound credentials reduces fragility during role changes, offboarding, and secret rotation. For organizations operationalizing AI coding and internal developer platforms, this is foundational for wiring GitHub usage into FinOps, BI, and governance systems.

Key takeaways: - Enterprise billing APIs can now be accessed through GitHub Apps instead of relying on personal access tokens. - App tokens provide a more durable automation boundary and higher API rate limits for finance, budgeting, cost allocation, and reporting workflows.

Tags: GitHub Apps, Enterprise Governance, FinOps, Platform Engineering Scores: signal 7/5, novelty 6/5, actionability 8/5

Enterprise-managed settings now support autoUpdate for plugin marketplaces

  • Source: GitHub Changelog
  • Author: N/A
  • Publish date: 2026-08-26
  • URL: https://github.blog/changelog/2026-08-26-enterprise-managed-settings-now-support-autoupdate-for-plugin-marketplaces/

GitHub Copilot enterprise-managed settings now support autoUpdate: true on extraKnownMarketplaces entries, allowing supported clients to automatically check and update installed plugins from approved marketplaces. The behavior still respects the strictKnownMarketplaces allowlist and applies across the GitHub Copilot app, Copilot CLI, and VS Code.

Why it matters: This signals that AI coding tooling is moving into a more mature enterprise plugin-governance phase: not just controlling which extension sources are allowed, but also centrally managing update behavior. For organizations concerned about prompt injection, tool-permission drift, or plugin supply-chain risk, centralized updates plus allowlists are important prerequisites for broader agent/tool adoption.

Key takeaways: - Enterprises can enable auto-updates for approved plugin marketplaces to reduce manual maintenance. - Auto-update remains gated by strictKnownMarketplaces, reinforcing source-control and governance.

Tags: Copilot Enterprise, Plugin Governance, Supply Chain, Developer Tooling Scores: signal 5/5, novelty 5/5, actionability 7/5
